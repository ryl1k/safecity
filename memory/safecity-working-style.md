For SafeCity planning, the user (ryl1k) likes to work **topic by topic**: dig into one topic with focused clarifying questions, write a rich KB note when the topic feels solid, and extend it later (notes are living docs). They prefer the **AskUserQuestion** structured-options format for decisions, and will sometimes re-answer a single question to give a fuller (multi-select) answer — re-ask just that one when they do.

**Why:** they explicitly asked to "ask clarifying questions till almost all is done" and to build "a perfect knowledge base of the project."

**How to apply:** lead with a short reasoning/recommendation before each question set; mark recommended options; be honest about scope/risk (they chose an ambitious MVP and value candor over cheerleading); commit notes/tasks to the `board` MCP. See [[safecity-project]].
